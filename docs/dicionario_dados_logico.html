Dicionário de Dados Lógico — Palazio del Chef

Entrega 2 · Modelagem de Banco de Dados (UNICID) · modelo do arquivo 02-03g da disciplina · todos os exemplos e dados são fictícios.

1. Convenções

  • SGBD: MySQL 8.0, mecanismo InnoDB (transações, chaves estrangeiras e CHECK aplicados). Codificação: utf8mb4, collation utf8mb4_0900_ai_ci.
  • Prefixos: ID_ identificador, NM_ nome, DT_ data, DH_ data e hora, QT_ quantidade, VL_ valor monetário, NR_ número, TP_ tipo/situação (caractere), IN_ indicador booleano, DS_ descrição/texto livre.
  • Restrições por coluna: Obrigatório (NOT NULL), Único (UNIQUE), Padrão (DEFAULT) e Valores permitidos (CHECK de uma só coluna). CHECK que envolve várias colunas aparece abaixo de cada tabela. Descrições e regras de negócio (RNxx) vêm do dicionário conceitual do README (seção 5.4).
  • Exemplos de valores: fictícios. Senhas guardadas como hash SHA-256 com sal (RNF03).
  • Versão: v1.0 do dicionário lógico, 21/10/2026, gerada do catálogo do banco por entrega-2/scripts/gerar_dicionario_logico.py.
